## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Build CSS**
   ```bash
   npm run sass:build
   ```

3. **Development Mode** (with file watching)
   ```bash
   npm run dev
   ```

4. **Open in Browser**
   - Open `index.html` in your browser
   - All pages are fully functional and responsive
